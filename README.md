# Expressive-Animator-1.1-Free-Offline
Freedom to Creativity. Expressive Animator is Free and Open Source for everyone. Source code is provided for Free for Windows, Linux and Mac. However, Python 3.10 http.server is provided for Windows 11 x64 only. Download compatible Python for your device.

# Steps for Windows 11 64bit Offline Local Installation
1. First run the server.bat or expressive-animator-server

2. then go to any broswer Chrome, Edge, Opera (Chromium based not Brave)

3. Type localhost:8000 and Enter. (You can save the site as Web app in the broswer (Edge or Chrome) by going
   three dots, more tools (or cast, save, share), save this site as App) (Hurrah, you have an Web App)

4. Run the app by searching in Start Menu. No internet required. Complete Local Installtion and Local Web App.
5. Make your all assets, images, drawings in Inkscape or Affinity Studio (Vector) or Cavlary by Canva for Free and then import in
   Expressive Animator to add animations and export in SVG, JS or other format. Complete workflow pipline should be this.
   
6. Caveats: You can't change your assets, layers name in the app. Also you can't add text with your local fonts.
   You need to name your assets, layers in Inkscape, Affinity or Cavlary and also convert your preferred local font text to path for imports in the App.
   Also you should always save your projects in .eaf format in the App. And your can open your .eaf files by first opening the app and then opening the .eaf file.
   Once, you created your svg file or other file than .eaf file, you can't import the animations, or project workflow you created, in the App. So, it
   is best Advice to keep the original file as a .eaf file and save your imported assets in dedicated folder.

7. Create beautiful Websites, Apps. Import your animated svg in Figma for App design, web design. Grow your Producitvity.

8. Enjoy and florish your creativity in Vector Animation. Create beautiful Websites, Apps. Let the Freedom reign. Free Software for everyone.
